# Zaawansowana robotyka inteligentna (ZRI)

Filtr cząsteczkowy — materiały i zadania kursowe.

## Struktura

| Folder | Opis |
|--------|------|
| `materialy/` | PDF z zajęciami |
| `zadanie_1_filtr_1D/` | Filtr 1D (notebooki) |
| `zadanie_2_filtr_2D/` | Filtr 2D na kratce 5×5 + demo |
| `zadanie_3_demo/` | Interaktywne demo 2D (ciągłe, z θ) |

## Uruchomienie dem

```bash
# zadanie 2 — kratka
python zadanie_2_filtr_2D/demo_filtr_2D_kratka.py

# zadanie 3 — mapa ciągła
python zadanie_3_demo/demo_filtr_2D.py
```

Wymagania: Python 3 + `numpy`, `matplotlib`.
